💬 Durable Conversation Checkpoints

The standout feature of our architecture. When an automation needs a customer answer, it creates a persistent checkpoint in MySQL and waits.

💾

Survives Server Restarts

State is saved in wa_automation_checkpoints with expiration windows. Reboots will never drop active conversations.

🎯

Strict Input Validation

Validates numbers, phone formats, YYYY-MM-DD dates, or choice lists before resuming the pipeline.

wa_automation_checkpoints.schema 
CREATE TABLE wa_automation_checkpoints (
  id INT AUTO_INCREMENT PRIMARY KEY,
  rule_id INT NOT NULL,
  contact_id INT,
  phone VARCHAR(32) NOT NULL,
  question_key VARCHAR(64),
  expected_type ENUM('text','choice','number','date'),
  status ENUM('pending','completed','expired'),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
