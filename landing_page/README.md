# MADHURA — Standalone Landing Page & Marketing Website

This project is a dedicated, independent marketing and landing page application for **MADHURA WhatsApp CRM & Automation**.

## 🚀 Running Independently

```bash
cd landing_page
npm install
npm run dev
```

The standalone landing page will launch at `http://localhost:3002`.

## 📦 Project Architecture & Scripts

- `npm run dev`: Runs the local Vite development server on port **3002** (zero port conflicts with the main dashboard on 3000/3001 and backend API on 5001).
- `npm run build`: Bundles an optimized, production-ready static website in `landing_page/dist`.
- `npm run preview`: Previews the production build locally.
